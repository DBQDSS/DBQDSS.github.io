Overview

之前我们的 TD Learning 所用数据是基于表格（tabular representation）的。本章的 主要想法 是：

  • 将 tabular representation 拓展为 function representation
  • 将神经网络与强化学习相结合
    • 例如，把神经网络引入 Q-learning，产生出经典的 DQN 算法

Outline

  1. 动机示例：曲线拟合
  2. state value 估计算法：如何建立目标函数、优化算法、用什么去近似
  3. action value 的估计算法：
    1. 值函数近似的 Sarsa
    2. 值函数近似的 Q-learning
  4. optimal action value 的估计算法：DQN
  5. 总结

从表格到函数

假设有一维状态 s1,…,s∣S∣s_1, \ldots, s_{|\mathcal{S}|}s1​,…,s∣S∣​，状态值为 vπ(s1),…,vπ(s∣S∣)v_\pi(s_1), \ldots, v_\pi(s_{|\mathcal{S}|})vπ​(s1​),…,vπ​(s∣S∣​)。假设 ∣S∣|\mathcal{S}|∣S∣ 非常大，我会希望用简单曲线近似这些点以节省存储。


以函数来节省存储

首先，我们使用最简单的直线来拟合这些点。假设该直线的方程为

v^(s,w)=as+b=[s,1]⏟ϕT(s)[ab]⏟w=ϕT(s)w\hat{v}(s, w) = as + b = \underbrace{[s, 1]}_{\phi^T(s)} \underbrace{\begin{bmatrix} a \\ b \end{bmatrix}}_{w} = \phi^T(s)w v^(s,w)=as+b=ϕT(s)[s,1]​​w[ab​]​​=ϕT(s)w

其中

  • www 是参数向量
  • ϕ(s)\phi(s)ϕ(s) 是 sss 的特征向量
  • v^(s,w)\hat{v}(s, w)v^(s,w) 关于 www 是线性的

函数表示的优点

  • 表格表示需要存储 ∣S∣|\mathcal{S}|∣S∣ 个状态值。而现在，我们只需存储两个参数 aaa 和 bbb。
  • 每当我们想要使用状态 sss 的值时，都可以通过计算 ϕT(s)w\phi^T(s)wϕT(s)w 得到。
  • 然而，这种好处并非免费的。它是有代价的：状态值无法被精确表示。这就是为什么这种方法被称为 值函数近似（value function approximation）。

其次，我们也可以使用二阶曲线来拟合这些点：

v^(s,w)=as2+bs+c=[s2,s,1]⏟ϕT(s)[abc]⏟w=ϕT(s)w\hat{v}(s, w) = as^2 + bs + c = \underbrace{[s^2, s, 1]}_{\phi^T(s)} \underbrace{\begin{bmatrix} a \\ b \\ c \end{bmatrix}}_{w} = \phi^T(s)w v^(s,w)=as2+bs+c=ϕT(s)[s2,s,1]​​w​abc​​​​=ϕT(s)w

在这种情况下，

  • www 和 ϕ(s)\phi(s)ϕ(s) 的维度增加了，但值可能被拟合得更加精确。
  • 尽管 v^(s,w)\hat{v}(s, w)v^(s,w) 关于 sss 是 非线性 的，但它关于 www 是 线性 的。非线性被包含在 ϕ(s)\phi(s)ϕ(s) 中。

第三，我们可以使用甚至更高阶的多项式曲线或其他复杂曲线来拟合这些点。

  • 优点：可以更好地近似。
  • 缺点：需要更多的参数。

小结

  • 思想：使用 参数化函数（parameterized functions）来近似状态和动作值：v^(s,w)≈vπ(s)\hat{v}(s, w) \approx v_\pi(s)v^(s,w)≈vπ​(s)，其中 w∈Rmw \in \mathbb{R}^mw∈Rm 是参数向量。
  • 优点：
    1. 存储：www 的维度可能 远小于 ∣S∣|\mathcal{S}|∣S∣。
    2. 泛化：当访问某个状态 sss 时，参数 www 会被更新，从而使得一些其他 未访问过 的状态的值也能随之被更新。

状态值估计算法

Lec 36 & 37 & 38

设 vπ(s)v_\pi(s)vπ​(s) 为真实状态值，v^(s,w)\hat{v}(s, w)v^(s,w) 为近似函数。目标：当函数结构确定的时候（已知 ϕT(s)\phi^T(s)ϕT(s)），找到最优 www 使得 v^(s,w)\hat{v}(s, w)v^(s,w) 最佳近似 vπ(s)v_\pi(s)vπ​(s)。

因此这个问题本质上是一个 policy evaluation：给定一个 policy π\piπ，我们需要用 v^(s,w)\hat{v}(s, w)v^(s,w) 去求真实的 vπ(s)v_\pi(s)vπ​(s)。

上面的想法可以推广为求 action value，然后进一步推广为求 optimal policy。

想实现这一点，我们需要分两步进行：

  1. 定义一个合适的目标函数
  2. 对目标函数进行优化

目标函数

以下就是值函数近似方法（value function approximation）对应的 目标函数：

J(w)=E[(vπ(S)−v^(S,w))2]J(w) = \mathbb{E}[(v_\pi(S) - \hat{v}(S, w))^2] J(w)=E[(vπ​(S)−v^(S,w))2]

其中的 SSS 是一个随机变量，状态 SSS 的概率分布有两种选择：

  1. 均匀分布：所有状态同等重要。

    J(w)=1∣S∣∑s(vπ(s)−v^(s,w))2J(w) = \frac{1}{|\mathcal{S}|}\sum_s (v_\pi(s) - \hat{v}(s, w))^2 J(w)=∣S∣1​s∑​(vπ​(s)−v^(s,w))2

    缺点是不考虑策略下 Markov 过程的真实动态。
  2. 平稳分布：更频繁访问的状态权重更高。

J(w)=∑s(vπ(s)−v^(s,w))2=∑s∈Sdπ(s)(vπ(s)−v^(s,w))2J(w) = \sum_s (v_\pi(s) - \hat{v}(s, w))^2 = \sum_{s \in \mathcal{S}} d_\pi(s)(v_\pi(s) - \hat{v}(s, w))^2 J(w)=s∑​(vπ​(s)−v^(s,w))2=s∈S∑​dπ​(s)(vπ​(s)−v^(s,w))2

其中，{dπ(s)}s∈S, dπ(s)≥0\{d_\pi(s)\}_{s \in \mathcal{S}}, \ d_\pi(s) \ge 0{dπ​(s)}s∈S​, dπ​(s)≥0 描述策略 π\piπ 下 Markov 过程的长期行为。

关于稳态分布的更多解释

  • 平稳（Stationary）：长期行为
  • 分布（Distribution）：状态的分布
  • 稳态：当智能体按照某个策略运行很长时间后，智能体处于任意状态的概率都可以用这个分布来描述。

备注：

  • 平稳分布也被称为 稳态分布（steady-state distribution） 或 极限分布（limiting distribution）。
  • 理解它对掌握值函数近似方法至关重要。
  • 它对下一讲中的策略梯度方法也很重要。

优化算法

既然我们有了目标函数，下一步就是对其进行优化。

  • 为了最小化目标函数 J(w)J(w)J(w)，我们可以使用 梯度下降（gradient-descent）算法：

wk+1=wk−αk∇wJ(wk)w_{k+1} = w_k - \alpha_k \nabla_w J(w_k) wk+1​=wk​−αk​∇w​J(wk​)

梯度下降

真实梯度为：

∇wJ(w)=∇wE[(vπ(S)−v^(S,w))2]=E[∇w(vπ(S)−v^(S,w))2]=2E[(vπ(S)−v^(S,w))(−∇wv^(S,w))]=−2E[(vπ(S)−v^(S,w))∇wv^(S,w)]\begin{align*} \nabla_w J(w) &= \nabla_w \mathbb{E}\left[(v_\pi(S) - \hat{v}(S, w))^2\right] \\ &= \mathbb{E}\left[\nabla_w (v_\pi(S) - \hat{v}(S, w))^2\right] \\ &= 2\mathbb{E}\left[(v_\pi(S) - \hat{v}(S, w))(-\nabla_w \hat{v}(S, w))\right] \\ &= -2\mathbb{E}\left[(v_\pi(S) - \hat{v}(S, w))\nabla_w \hat{v}(S, w)\right] \end{align*}∇w​J(w)​=∇w​E[(vπ​(S)−v^(S,w))2]=E[∇w​(vπ​(S)−v^(S,w))2]=2E[(vπ​(S)−v^(S,w))(−∇w​v^(S,w))]=−2E[(vπ​(S)−v^(S,w))∇w​v^(S,w)]​

函数逼近器的选择

一个尚未回答的重要问题是：如何选择函数 v^(s,w)\hat{v}(s, w)v^(s,w)？

  • 第一种方法，也是以前广泛使用的方法，是使用线性函数：

    v^(s,w)=ϕT(s)w\hat{v}(s, w) = \phi^T(s)w v^(s,w)=ϕT(s)w

    这里，ϕ(s)\phi(s)ϕ(s) 是特征向量，可以是 多项式基（polynomial basis）、傅里叶基（Fourier basis）、……（详见教材）
  • 第二种方法，也是 当今广泛使用 的方法，是使用神经网络作为 非线性 函数近似器。
    • 神经网络的输入是状态，输出是 v^(s,w)\hat{v}(s, w)v^(s,w)，网络参数是 www

这就是基于线性函数近似的 TD 学习算法。在本课程中，我们简称为 TD-Linear。

线性函数近似的优缺点：

  • 缺点：
    • 难以选择合适的特征向量。
  • 优点：
    • 线性情况下 TD 算法的理论性质比非线性情况更容易理解。
    • 线性函数近似仍然很强大，因为表格表示仅仅是线性函数近似的一个特例。

  • 它是将深度神经网络引入强化学习的最早且最成功的算法之一。
  • 神经网络的作用是作为一个非线性函数近似器。
  • 它与下面的算法不同：

原因在于：训练网络的方式不同。

DQN 的目标函数

深度 Q 学习旨在最小化以下目标函数/损失函数：

J(w)=E[(R+γmax⁡a∈A(S′)q^(S′,a,w)−q^(S,A,w))2],J(w) = \mathbb{E}\left[\left(R + \gamma \max_{a \in \mathcal{A}(S^\prime)} \hat{q}(S^\prime, a, w) - \hat{q}(S, A, w)\right)^2\right], J(w)=E[(R+γa∈A(S′)max​q^​(S′,a,w)−q^​(S,A,w))2],

其中 (S,A,R,S′)(S, A, R, S^\prime)(S,A,R,S′) 是随机变量。

  • 这实际上是 贝尔曼最优误差（Bellman optimality error）。因为：

q(s,a)=E[Rt+1+γmax⁡a∈A(St+1)q(St+1,a)|St=s,At=a],∀s,aq(s, a) = \mathbb{E}\left[R_{t+1} + \gamma \max_{a \in \mathcal{A}(S_{t+1})} q(S_{t+1}, a) \middle| S_t = s, A_t = a\right], \quad \forall s, a q(s,a)=E[Rt+1​+γa∈A(St+1​)max​q(St+1​,a)​St​=s,At​=a],∀s,a

因此，R+γmax⁡a∈A(S′)q^(S′,a,w)−q^(S,A,w)R + \gamma \max_{a \in \mathcal{A}(S^\prime)} \hat{q}(S^\prime, a, w) - \hat{q}(S, A, w)R+γmaxa∈A(S′)​q^​(S′,a,w)−q^​(S,A,w) 的值在期望意义下应该为零。

如何最小化目标函数？梯度下降！

  • 如何计算目标函数的梯度？这很棘手！
  • 这是因为，在该目标函数

J(w)=E[(R+γmax⁡a∈A(S′)q^(S′,a,w)−q^(S,A,w))2],J(w) = \mathbb{E}\left[\left(R + \gamma \max_{a \in \mathcal{A}(S^\prime)} \hat{q}(S^\prime, a, w) - \hat{q}(S, A, w)\right)^2\right], J(w)=E[(R+γa∈A(S′)max​q^​(S′,a,w)−q^​(S,A,w))2],

参数 www 不仅出现在 q^(S,A,w)\hat{q}(S, A, w)q^​(S,A,w) 中，还出现于

y≐R+γmax⁡a∈A(S′)q^(S′,a,w)y \doteq R + \gamma \max_{a \in \mathcal{A}(S^\prime)} \hat{q}(S^\prime, a, w) y≐R+γa∈A(S′)max​q^​(S′,a,w)

  • 为了简化，我们可以假设在计算梯度时，yyy 中的 www 是固定的（至少在一段时间内固定）。

主网络与目标网络

为此，我们可以引入两个网络：

  • 一个是主网络（main network），表示 q^(s,a,w)\hat{q}(s, a, w)q^​(s,a,w)；
  • 另一个是目标网络（target network） q^(s,a,wT)\hat{q}(s, a, w_T)q^​(s,a,wT​)。

经验回放

实现 DQN 的另一个关键技术是 经验回放（Experience replay）

  • 问题：什么是经验回放？
  • 回答：
    • 在收集了一些经验样本后，我们不按它们被收集的顺序使用这些样本。
    • 相反，我们将它们存储在一个集合中，称为经验回放池（replay buffer） B≐{(s,a,r,s′)}\mathcal{B} \doteq \{(s, a, r, s^\prime)\}B≐{(s,a,r,s′)}。
    • 每次训练神经网络时，我们可以从经验回放池中随机抽取一个小批量样本。
    • 抽取样本（称为经验回放）应该遵循均匀分布（为什么？）。

  • 答案在于目标函数!

考察目标函数：

J=E[(R+γmax⁡a∈A(S′)q^(S′,a,w)−q^(S,A,w))2]J = \mathbb{E}\left[\left(R + \gamma \max_{a \in \mathcal{A}(S^\prime)} \hat{q}(S^\prime, a, w) - \hat{q}(S, A, w)\right)^2\right] J=E[(R+γa∈A(S′)max​q^​(S′,a,w)−q^​(S,A,w))2]

  • (S,A)∼d(S, A) \sim d(S,A)∼d：(S,A)(S, A)(S,A) 是一个索引，被视为单个随机变量。
  • R∼p(R∣S,A),S′∼p(S′∣S,A)R \sim p(R|S, A), S^\prime \sim p(S^\prime|S, A)R∼p(R∣S,A),S′∼p(S′∣S,A)：RRR 和 S′S^\primeS′ 由系统模型决定。
  • 状态-动作对 (S,A)(S, A)(S,A) 的分布被假定为均匀的。
    • 然而，样本并非均匀收集的，因为它们是由特定策略连续生成的。
    • 为了打破连续样本之间的相关性，我们可以使用经验回放技术，从经验回放池中均匀抽取样本。

这就是经验回放必要以及经验回放必须均匀的数学原因！

重新审视表格型情况

  • 问题： 为什么表格型 Q-Learning 不需要经验回放？
    • 因为之前没有涉及到 (s,a)(s,a)(s,a) 分布的要求。
  • 问题： 为什么 DQN 涉及分布？
    • 深度网络情况下的目标函数是所有 (S,A)(S, A)(S,A) 上的标量平均。表格型情况不涉及 SSS 或 AAA 的任何分布。表格型情况的算法旨在为所有 (s,a)(s, a)(s,a) 求解一组方程（贝尔曼最优方程）。
    • 一个是在优化目标函数，一个是在求解方程。
  • 问题： 我们可以在表格型 Q-Learning 中使用经验回放吗？
    • 可以。而且这样更具样本效率（为什么？）。
      • 因为 tabular 形式的 Q-learning 也是 off-policy 的，所以可以复用技巧。
      • 此外，经验回放可以提升样本利用效率——同一个 sample 可以用多次。
        • 例如：之前 tabular Q-learning 中，为了达到较好的效果，我们一个 episode 需要运行 10w 步，实际上根本不需要这么多步！只需要保证每个 state-action pair 被访问一次就行了，以前是按照时序来采的，使用完数据即丢弃的做法其实很浪费。

伪代码：Deep Q-learning（异策略版本）

目标： 学习一个最优目标网络，以根据由行为策略 πb\pi_bπb​ 生成的经验样本近似最优动作值。

  • 将由 πb\pi_bπb​ 生成的经验样本存储在经验回放池 B={(s,a,r,s′)}\mathcal{B} = \{(s, a, r, s^\prime)\}B={(s,a,r,s′)} 中。
    • 对于每次迭代，执行：
      • 从 B\mathcal{B}B 中均匀抽取一个小批量样本
      • 对于每个样本 (s,a,r,s′)(s, a, r, s^\prime)(s,a,r,s′)，计算目标值：
        • yT=r+γmax⁡a∈A(s′)q^(s′,a,wT)y_T = r + \gamma \max_{a \in \mathcal{A}(s^\prime)} \hat{q}(s^\prime, a, w_T)yT​=r+γmaxa∈A(s′)​q^​(s′,a,wT​)
        • 其中 wTw_TwT​ 是目标网络的参数
      • 使用小批量 {(s,a,yT)}\{(s, a, y_T)\}{(s,a,yT​)} 更新主网络以最小化 (yT−q^(s,a,w))2(y_T - \hat{q}(s, a, w))^2(yT​−q^​(s,a,w))2
    • 每 CCC 次迭代设置 wT=ww_T = wwT​=w

备注：

  • 为什么没有策略更新？
    • 因为我们是 off-policy 的，因此不需要每步的策略更新——只需要在最后一次迭代之后一步算出 optimal policy。
    • 如果是 on-policy 的，那么每步迭代必须有 policy improvement。
  • 为什么不使用我们推导出的策略更新方程？
    • 这是为了适配当前神经网络的特性，用于高效训练。
  • 网络的输入和输出与 DQN 论文中的不同。
    • DQN 原文中是 on-policy 的，这里是 off-policy 的，但二者本质相同。

示例说明

  • 本示例旨在学习每个状态-动作对的最优动作值。
  • 一旦获得最优动作值，就可以立即得到最优贪婪策略。

实验设置：

  • 使用 单个回合（episode） 来训练网络。
  • 该回合由图 (a) 所示的探索性**行为策略（behavior policy）**生成。
  • 该回合仅有 1,000 步！而表格型 Q-Learning 需要 100,000 步。
  • 使用一个具有单个隐藏层的浅层神经网络作为 q^(s,a,w)\hat{q}(s, a, w)q^​(s,a,w) 的非线性近似器。隐藏层有 100 个神经元。
    • 输入层-隐藏层-输出层

使用 1000 步的单回合

可以看到：

  • TD error 收敛到零
  • state value 误差无法收敛到零

这说明 DQN 使用很少的数据量就能达到 tabular Q-learning 的效果。

这有两个原因：

  1. value function approximation 本身就具有比较强的泛化能力
  2. experience replay 可以让经验被反复用到，效率会比较高
